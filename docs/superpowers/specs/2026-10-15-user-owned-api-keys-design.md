# 用户自带 API Key 与加密保存设计

日期：2026-10-15。状态：用户已同意功能与安全原则，本文待审阅；未实施、未部署。

## 目标与边界

公开网页使用访问者自己的模型 API Key，模型调用费用计入访问者的 API 账号。
项目所有者仍承担网站、后端计算和存储费用。任何失败都不得回退到所有者的模型或搜索密钥。
用户可明确同意保存自己的 Key，下次登录后继续使用，也可替换或删除。
服务器会接触和解密用户 Key；不得声称 Key 不离开浏览器，或平台绝对无法访问。
本变更不授权传输所有者已有凭据，不授权现在部署，也不改变历史 GAIA 成绩。

## 当前实现与需改动的位置

已只读检查现有网页工作树：交互 API 在应用启动时从环境读取 OPENAI_API_KEY，
composition 按配置创建 Provider；身份来自 Sites 登录，由服务端代理传递给 Python 后端。
需要增加凭据管理模块，将公共网页执行路径改成按用户、按任务创建配置与客户端。
现有离线 benchmark/CLI 配置继续保留；禁止公共网页执行路径读取其所有者凭据。
凭据不得写入 InteractiveRequest、任务记录、研究笔记或模型上下文。

## 选择与取舍

1. 推荐：服务端按账号加密保存。满足跨设备、重新登录后继续使用；需要保管加密主密钥。
2. 浏览器本地保存：不满足可靠的跨设备体验，持久化明文还增加浏览器侧暴露面，不采用。
3. 仅会话内存：保留为不勾选“保存 Key”时的选项，但不能替代用户要求的持久保存。

## 身份、接口与界面

- 凭据归属只从受信任的登录身份确定，不能接受浏览器提供的 owner/user_id。
- 设置页使用密码输入框；“保存 Key，下次登录使用”默认不勾选，旁边明确告知服务端保存和调用。
- 密钥提交仅使用 HTTPS 的 POST/PUT 请求体；不得放进 URL、cookie、聊天或 localStorage。
- 新增受认证保护的凭据状态、保存/替换、删除接口，沿用现有同源校验与代理服务认证。
- 状态接口只返回 provider、是否已配置、末尾四位、更新时间；不得提供明文读取/导出接口。
- 不保存模式采用短期内存凭据句柄：绑定登录用户，30 分钟失效，任务最长执行时间内保留。
  页面刷新或服务重启后可能需要重新输入。句柄不包含 Key，本身不能绕过身份校验。
- 保存失败、额度不足、凭据无效、模型不可用均显示安全错误码；不展示上游原始异常。

## 加密与持久化

- 后端使用成熟库的 AES-256-GCM 进行认证加密，每次写入生成全新随机 nonce。
- 关联数据绑定内部用户 ID、provider 和格式版本，防止密文被调换到其他用户或服务商。
- 数据库仅存密文、nonce、密钥版本、provider、末尾四位、同意时间及更新时间。
- 加密主密钥由部署平台的服务端 Secret 提供，与数据库分开；缺少主密钥时拒绝凭据写入和解密。
  不生成临时主密钥冒充持久配置，不将其写入 Git、数据库或浏览器。
- 保存与替换采用原子更新。解密完整性校验失败时拒绝执行，不尝试其他账号或全局凭据。
- 主密钥使用版本标识，轮换时保留旧版本直至迁移完成；丢失主密钥意味着需要用户重新输入。
- 删除移除在线数据库中的密文并清除对应内存句柄；同时取消该用户活动任务，尽力停止后续调用。
  已发送给模型服务的请求无法撤回，可能仍产生费用。用户需要立即彻底撤销访问时应在服务商处撤销 Key。
- 不承诺物理擦除备份或 Python 内存。该版本不添加凭据备份/导出；发布前必须核实托管平台快照保留，
  并在隐私说明中写明已配置的实际保留期。未核实前不宣称“删除后所有副本立即消失”。

## 执行与费用隔离

- 每个任务解析其发起用户的凭据，创建独立 Provider 和工具客户端；禁止修改进程级 os.environ。
- 模型、视觉、音频、托管工具等所有付费调用都使用同一发起用户的相应凭据。
- 固定模型偏好保持为 gpt-6.1-sol / low；这不是所有 API 账号可用性的承诺。
  用户账号或接入服务不支持时明确失败，不静默切换模型、服务商或所有者 Key。
- 首版沿用单一管理员配置并允许的模型服务地址；用户不能提交任意 base_url，避免将 Key 发送到任意地址。
  UI 必须明确显示实际接收 Key 的服务商/域名；未确认该服务商与模型访问能力前不开放使用。
- 独立搜索服务只在用户另行提供对应 Key 时启用；否则禁用，不回退到环境中的搜索密钥。
  模型服务自带搜索的费用仍计入用户模型账号，并在界面说明。
- 子进程仅注入该用户所需的最小凭据集，清理继承的所有者 OPENAI/SERPER/SERPAPI 凭据。
  任务结束关闭客户端并释放引用；不声称运行时内存得到不可恢复的清零。
- 保留每用户限流、全局并发、超时和工具预算；这些是资源限制，不是用户账单的硬金额上限。

## 日志与泄露防护

代理和后端不记录凭据请求体、认证头、解密值或上游原始异常。
新增接口关闭请求体采集与异常输入回显；错误通过明确白名单分类，不只依赖字符串脱敏。
凭据不得出现在任务结果、工具参数审计、第三方追踪、网页构建产物或客户端源码中。
密钥设置操作只记录无敏感值的事件与成功/失败码。

## 验证与发布门槛

1. 加密往返；同一 Key 重复保存密文不同；篡改、用户互换和主密钥缺失均安全失败。
2. Alice/Bob 并发执行时模型、搜索与子进程凭据不串用；未认证和跨用户访问均拒绝。
3. 数据库、日志、错误响应、任务结果与浏览器构建产物中找不到测试用明文 Key。
4. 保存需要明确同意；状态只返回掩码；替换生效；删除后活动任务取消且下一次执行拒绝。
5. 未保存凭据过期/重启后不可用；缺失、无效、无额度或不支持模型时不回退到所有者 Key。
6. 启动公共服务时不需要所有者模型 Key；故意设置所有者测试凭据也不得被公共任务使用。
7. 先用模拟 Provider 完成隔离和错误测试。真实密钥仅由测试者在设置页主动输入，单独同意实际调用。
8. 发布前核实 HTTPS、真实登录、Secret 配置、托管快照保留和供应商地址，并更新隐私与费用说明。
